# security

if you find a vulnerability in anything here, please report it privately rather than in a public issue.

- on GitHub: open the repository's **Security** tab and choose **Report a vulnerability**
- by email: contact@fray.lol

say what you found, how to reproduce it, and what it lets someone do. you'll get a reply within a few days, and a fix is shipped before anything is made public. please don't test against other people's servers or data.
