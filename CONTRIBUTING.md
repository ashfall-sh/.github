# contributing

thanks for wanting to help.

- **bugs and ideas**: open an issue with the template. one problem or one idea per issue.
- **pull requests**: for anything bigger than a typo, open an issue first so we can agree on the approach before you spend time on it.
- **style**: match the code around your change. small, focused pull requests get merged fastest.
- **security problems**: never in a public issue. see [SECURITY.md](SECURITY.md).

questions are welcome in the [support server](https://discord.gg/RztGdZYQt2).
